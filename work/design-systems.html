01 · Situation

What happened

Every company I worked with started from the same place: an inconsistent look across products, layouts that weren't fully responsive, and engineers building the same element again and again in slightly different colours and variants. Nothing scaled as requirements grew. At DYN there was no design system at all.

02 · Approach

What I did

I build design systems together with engineering, as the base for efficient development and a clean, consistent brand across the whole company.

  • Start from what's really thereWe break every existing design down into atoms, components and templates, following Atomic Design, before adding anything new.
  • Build the foundation with engineeringDesign and development agree on the system together, so components in Figma match components in code.
  • Multi-brand from day oneAt DYN, where nothing existed yet, the system is built to carry several brands from the start.
  • AI as part of the teamWe build the system in cooperation with AI, in the workflow between design and code.
03 · Result

What it changed

The design systems I built made it simpler and more efficient for everyone to implement designs, and design changes can be rolled out quickly and consistently. Instead of bending a framework like Bootstrap to fit the brand, we build systems around our own business needs and improve them step by step. Even accessibility can be added later when the structure is sound.
